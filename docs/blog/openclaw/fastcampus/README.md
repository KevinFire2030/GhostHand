# 보안 걱정 끝! 오픈클로로 24시간 풀가동 AI 에이전트 만들기 w. Claude Code

패스트캠퍼스 온라인 강의 **「보안 걱정 끝! 오픈클로로 24시간 풀가동 AI 에이전트 만들기 w. Claude Code」**의 강의 소개서와 파트별 교안 모음입니다.

- 강의장: 온라인 강의
- 수강 기간: 평생 소장
- 강의 시간: 7시간 51분
- 상세페이지: <https://fastcampus.co.kr/biz_online_openclaw>
- 강사: 박준영

## 강의 목표

- OpenClaw를 활용해 여러 AI 에이전트를 동시에 운영하는 멀티 에이전트 시스템 구축 역량을 기릅니다.
- AI 에이전트의 역할 분리와 협업 구조를 설계하고, 실제 업무에 적용 가능한 자동화 흐름을 이해합니다.
- 에이전트 간 상호작용과 작업 분배 방식을 통해 효율적인 AI 작업 환경을 구성하는 방법을 학습합니다.

## 강의 요약

- 단순 기능 설명을 넘어 AI 에이전트를 어떻게 활용하고 어디까지 자동화할 수 있는지 다룹니다.
- 보안 전문가의 관점에서 OpenClaw를 안전하게 활용하는 방법을 함께 다룹니다.
- AI 에이전트를 팀처럼 운영하며 업무 효율을 높이는 자동화 시스템 구축 과정을 학습합니다.
