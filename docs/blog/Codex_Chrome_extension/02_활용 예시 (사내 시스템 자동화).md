# Codex Chrome Extension 활용 예시: 사내 시스템 자동화

Codex Chrome Extension은 **API가 없고, 로그인 세션이 필요한 사내 시스템 자동화**에 특히 유용하다.

사내 SaaS나 내부 업무 시스템은 외부 API가 제공되지 않거나, API 권한을 받기 어렵거나, SSO/VPN/사내 인증 때문에 실제 브라우저 로그인 세션이 필요한 경우가 많다. 이럴 때 Codex Chrome Extension을 사용하면 사용자의 Chrome 브라우저에 로그인된 상태를 활용해 기존 웹 UI 기반 업무를 자동화하거나 반자동화할 수 있다.

## 적용하기 좋은 사내 시스템 예시

- GSCM: 주문, 공급망, 입고, 출고, 재고, 발주 상태 조회
- ERP: 거래처, 품목, 전표, 구매, 정산, 승인 상태 확인
- myFinance: 경비 처리, 영수증 확인, 비용 항목 입력, 정산 초안 작성
- 사내 포털: 공지, 결재, 인사 정보, 업무 요청 확인
- 내부 SaaS: API 없이 웹 화면으로만 제공되는 운영 도구

## 왜 Chrome Extension이 유용한가

일반적인 자동화는 API가 있으면 API를 사용하는 것이 가장 안정적이다. 하지만 사내 시스템에서는 다음과 같은 제약이 자주 있다.

- 공식 API가 없다.
- API가 있어도 일부 기능만 제공된다.
- API 사용 권한을 받는 데 시간이 오래 걸린다.
- SSO, 2FA, VPN, 사내망 인증이 필요하다.
- 웹 UI에서만 가능한 업무 흐름이 있다.
- 기존 업무 담당자가 브라우저 화면 기준으로 검토해야 한다.

이런 경우 Codex Chrome Extension은 사용자의 실제 Chrome 프로필과 로그인 세션을 활용할 수 있으므로, API 없이도 웹 화면 기반 업무를 보조할 수 있다.

## 적합한 자동화 시나리오

### 1. 조회 및 요약

사내 시스템에서 정보를 조회하고 핵심 내용을 요약하는 작업에 적합하다.

- GSCM에서 주문 번호별 진행 상태 확인
- ERP에서 거래처 기본 정보 조회
- myFinance에서 경비 신청 상태 확인
- 특정 기간의 승인 대기 건 목록 정리
- 화면에 보이는 데이터를 표 형태로 요약

조회 업무는 시스템 변경 위험이 낮아 자동화 도입의 첫 단계로 좋다.

### 2. 데이터 입력 초안 작성

반복적인 입력 양식을 미리 채우는 작업에도 유용하다.

- myFinance 경비 항목 초안 입력
- ERP 전표 입력 전 필드 초안 작성
- GSCM 발주 관련 메모 입력
- 사내 포털 업무 요청서 초안 작성

다만 금액, 계정과목, 거래처, 승인자처럼 오류 비용이 큰 항목은 사용자가 마지막에 직접 확인하는 방식이 안전하다.

### 3. 시스템 간 복사 및 정리

한 시스템에서 확인한 내용을 다른 시스템에 옮기거나 정리할 때도 사용할 수 있다.

- ERP 거래처 정보를 GSCM 입력 화면에 참고
- myFinance 경비 내역을 보고용 표로 정리
- 사내 포털 신청 내용을 ERP 처리 메모로 정리
- 여러 화면에 흩어진 정보를 하나의 업무 요약으로 통합

이때 Codex는 화면을 읽고 정리하는 보조자 역할을 하고, 최종 입력이나 제출은 사용자가 확인하는 방식이 좋다.

## 특히 좋은 사용 조건

Codex Chrome Extension은 다음 조건이 겹칠수록 효과가 크다.

- API가 없는 시스템이다.
- 로그인된 Chrome 세션이 필요하다.
- SSO, VPN, 2FA 등 브라우저 기반 인증을 사용한다.
- 업무가 반복적이고 규칙적이다.
- 화면에 표시된 정보를 사람이 확인해야 한다.
- 완전 자동 제출보다 초안 작성과 검토 보조가 중요하다.

즉, **API는 없지만 사람이 매번 브라우저에서 반복 처리하는 업무**가 가장 좋은 후보군이다.

## 주의할 점

사내 시스템 자동화는 편리하지만, 변경 작업에는 항상 주의가 필요하다.

- 삭제, 승인, 제출, 결재, 정산, 발주 같은 작업은 사용자 확인을 거친다.
- 금액, 수량, 거래처, 계정과목, 승인자 정보는 자동 입력 후 검토한다.
- 대량 처리 작업은 먼저 소량 데이터로 테스트한다.
- 민감 정보가 포함된 화면은 필요한 범위만 사용한다.
- 시스템 정책상 자동화가 허용되는지 확인한다.

권장 방식은 완전 무인 자동화가 아니라 **사람이 최종 확인하는 반자동화**다.

## 구현 우선순위

사내 시스템 자동화를 설계할 때는 다음 순서를 추천한다.

1. API가 있으면 API를 우선 검토한다.
2. API가 없거나 권한 확보가 어렵다면 Chrome Extension 기반 UI 자동화를 검토한다.
3. 조회, 요약, 초안 작성처럼 위험이 낮은 업무부터 시작한다.
4. 제출, 승인, 삭제, 정산, 발주 같은 고위험 작업은 사용자 확인 단계를 넣는다.
5. 반복 업무가 안정화되면 자동화 범위를 점진적으로 넓힌다.

## 예시 워크플로

### myFinance 경비 처리 보조

1. 사용자가 myFinance에 로그인한다.
2. Codex가 경비 입력 화면을 연다.
3. 영수증 또는 메모 내용을 기준으로 항목 초안을 채운다.
4. 사용자가 금액, 계정과목, 결제일, 증빙을 확인한다.
5. 사용자가 최종 제출한다.

### ERP 거래처 정보 조회

1. 사용자가 ERP에 로그인한다.
2. Codex가 거래처 검색 화면에서 업체명을 조회한다.
3. 사업자번호, 담당자, 결제 조건, 최근 거래 상태를 확인한다.
4. Codex가 결과를 요약한다.
5. 사용자가 필요한 후속 업무를 결정한다.

### GSCM 주문 상태 확인

1. 사용자가 GSCM에 로그인한다.
2. Codex가 주문 번호 목록을 기준으로 상태를 조회한다.
3. 입고, 출고, 납기, 지연 여부를 확인한다.
4. Codex가 예외 건만 따로 정리한다.
5. 사용자가 담당자에게 공유하거나 후속 조치를 진행한다.

## 결론

Codex Chrome Extension은 GSCM, ERP, myFinance 같은 사내 시스템 자동화에 좋은 선택지가 될 수 있다.

특히 **API가 없고 로그인 세션이 필요한 사내 시스템**에서는 기존 웹 UI를 그대로 활용할 수 있어 도입 장벽이 낮다. 다만 업무상 영향이 큰 작업은 반드시 사용자 확인 단계를 포함하고, 조회와 요약, 입력 초안 작성처럼 위험이 낮은 영역부터 시작하는 것이 안전하다.
