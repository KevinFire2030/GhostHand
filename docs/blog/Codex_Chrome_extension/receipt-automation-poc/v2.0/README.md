# Receipt Automation PoC v2.0

영수증 업로드를 기반으로 경비정산을 자동화하는 PoC의 v2.0 작업 공간입니다.

## 목표

- 영수증 이미지/PDF 업로드
- OCR 및 LLM 기반 데이터 추출
- 날짜, 가맹점, 금액, 품목, 결제수단 등 핵심 필드 구조화
- 경비 항목 자동 분류
- 정산 초안 생성 및 검토 흐름 구성

## 예상 처리 흐름

1. 사용자가 영수증을 업로드합니다.
2. 시스템이 OCR로 텍스트를 추출합니다.
3. LLM/규칙 기반 파서가 정산 필드를 구조화합니다.
4. 정책/카테고리 기준에 따라 경비 항목을 분류합니다.
5. 검토 가능한 경비정산 초안을 생성합니다.

## 디렉터리 계획

- `sample/`: 테스트용 영수증 샘플 및 OCR 텍스트
- `src/`: PoC 구현 코드
- `docs/`: 설계 문서 및 데모 시나리오
- `tests/`: 테스트 코드
