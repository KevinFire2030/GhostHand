src 폴더에 아래 기능(PoC 데모용)을 하는 간단한 electron 앱을 생성해줘

0. 설정

0.0. 핵심 목표
- PoC 데모에서 보여주고 싶은 핵심 기능
. Electron 앱에서 api 호출로 오픈클로의 웹훅 호출
. 오픈클로에서 영수증 이미지를 스캔해서 추천 계정을 리턴
. Electron 앱 -> api 호출 -> 오픈클로 웹훅 -> 스킬 -> 리턴

0.1. 기능
- 사용자가 영수증 이미지를 업로드하면
- 영수증 이미지를 분석해서 가장 유사한 경비 정산 계정을 추천해 주는 앱

예)
영수증: 스타벅스
추천 정산 계정: 회의비

정산 계정예시: 회의비, 판촉비, 국내교통비, 물품구매 등

0.2. 화면구성
- 왼쪽: 입력
- 가운데: 처리
- 오른쪽: 출력

0.3. 기술스택
- Frontend: Electron 앱
- Backend: 오픈클로 에이전트
- 백엔드와 프론트엔드사이 통신: api 호출 -> 웹훅 endpoint

1. 입력
- 파일 선택 버튼을 눌러 영수증 이미지를 입력받는다


2. 처리
- api 호출 통해
- 이미지를 오픈클로에전달
- 오픈클로에서 이미지를 분석하여
- 가장 유사한 계정을 선택하여 이유와 함께 리턴

3. 출력
- 리턴 받은 계정과 이유를 출력


4. 고려사항
- 배포
. 사용자는 아무 설정없이 크냥 윈클릭으로 설치하여 사용할수 있게
. 모든 필요한 패키지는 하나의 설치 실행 파일에 포함

예시)
receipt-automation-poc-setup.exe

클릭하면 필요한 모든 패키지 자동설치하고 실행
